The Rust Programming Language

Alur Kontrol

Kemampuan untuk menjalankan beberapa kode tergantung pada apakah sebuah kondisi true dan kemampuan untuk menjalankan beberapa kode berulang kali selama kondisi true adalah blok bangunan dasar di kebanyakan bahasa pemrograman. Konstruksi paling umum yang memungkinkan Anda mengontrol alur eksekusi kode Rust adalah ekspresi if dan loop.

Ekspresi if

Ekspresi if memungkinkan Anda bercabang kode Anda tergantung pada kondisi. Anda memberikan kondisi dan kemudian menyatakan, “Jika kondisi ini terpenuhi, jalankan blok kode ini. Jika kondisi tidak terpenuhi, jangan jalankan blok kode ini.”

Buat proyek baru bernama _branches_ di direktori _projects_ Anda untuk mengeksplorasi ekspresi if. Di berkas _src/main.rs_, masukkan hal berikut:

Nama Berkas: src/main.rs

fn main() {
    let number = 3;

    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }
}

Semua ekspresi if diawali dengan kata kunci if, diikuti oleh sebuah kondisi. Dalam kasus ini, kondisi memeriksa apakah variabel number memiliki nilai kurang dari 5. Kami menempatkan blok kode yang akan dieksekusi jika kondisi true segera setelah kondisi di dalam tanda kurung kurawal. Blok kode yang terkait dengan kondisi di ekspresi if kadang disebut arms (lengan), sama seperti lengan di ekspresi match yang kami bahas di bagian “Membandingkan Tebakan dengan Angka Rahasia” di Bab 2.

Secara opsional, kami juga bisa menyertakan ekspresi else, yang kami pilih untuk melakukannya di sini, untuk memberikan program blok kode alternatif yang diekseskusi jika kondisi mengevaluasi ke false. Jika Anda tidak menyediakan ekspresi else dan kondisinya false, program akan hanya melewati blok if dan melanjutkan ke potongan kode berikutnya.

Coba jalankan kode ini; Anda seharusnya melihat keluaran berikut:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
condition was true

Mari coba mengubah nilai number ke nilai yang membuat kondisi false untuk melihat apa yang terjadi:

fn main() {
    let number = 7;

    if number < 5 {
        println!("condition was true");
    } else {
        println!("condition was false");
    }
}

Jalankan program lagi, dan lihat keluaran:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
condition was false

Pernyataannya juga layak dicatat bahwa kondisi dalam kode ini harus berupa bool. Jika kondisinya bukan bool, kami akan mendapat kesalahan. Misalnya, coba jalankan kode berikut:

Nama Berkas: src/main.rs

fn main() {
    let number = 3;

    if number {
        println!("number was three");
    }
}

Kondisi if kali ini mengevaluasi ke nilai 3, dan Rust melempar kesalahan:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: mismatched types
 --> src/main.rs:4:8
  |
4 |     if number {
  |        ^^^^^^ expected `bool`, found integer

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

Kesalahan menunjukkan bahwa Rust mengharapkan bool tapi mendapat integer. Berbeda dengan bahasa seperti Ruby dan JavaScript, Rust tidak akan secara otomatis mencoba mengubah tipe non-Boolean ke Boolean. Anda harus eksplisit dan selalu menyediakan if dengan Boolean sebagai kondisinya. Jika kami ingin blok kode if dijalankan hanya saat angka tidak sama dengan 0, misalnya, kami bisa mengubah ekspresi if menjadi berikut:

Nama Berkas: src/main.rs

fn main() {
    let number = 3;

    if number != 0 {
        println!("number was something other than zero");
    }
}

Menjalankan kode ini akan mencetak number was something other than zero.

Menangani Beberapa Kondisi dengan else if

Anda bisa menggunakan beberapa kondisi dengan menggabungkan if dan else dalam ekspresi else if. Misalnya:

Nama Berkas: src/main.rs

fn main() {
    let number = 6;

    if number % 4 == 0 {
        println!("number is divisible by 4");
    } else if number % 3 == 0 {
        println!("number is divisible by 3");
    } else if number % 2 == 0 {
        println!("number is divisible by 2");
    } else {
        println!("number is not divisible by 4, 3, or 2");
    }
}

Program ini memiliki empat jalur mungkin yang bisa diambil. Setelah menjalankannya, Anda seharusnya melihat keluaran berikut:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.31s
     Running `target/debug/branches`
number is divisible by 3

Saat program ini dieksekusi, ia memeriksa setiap ekspresi if secara berurutan dan mengeksekusi badan pertama yang kondisinya mengevaluasi ke true. Perhatikan bahwa meskipun 6 habis dibagi 2, kami tidak melihat keluaran number is divisible by 2, dan kami juga tidak melihat teks number is not divisible by 4, 3, or 2 dari blok else. Itu karena Rust hanya mengeksekusi blok untuk kondisi true pertama, dan begitu ia menemukan satu, ia bahkan tidak memeriksa sisanya.

Menggunakan terlalu banyak ekspresi else if bisa mengacaukan kode Anda, jadi jika Anda memiliki lebih dari satu, Anda mungkin ingin merefaktorkan kode Anda. Bab 6 mendeskripsikan konstruksi bercabang Rust yang powerful bernama match untuk kasus-kasus ini.

Menggunakan if di Pernyataan let

Karena if adalah ekspresi, kita bisa menggunakannya di sisi kanan pernyataan let untuk menetapkan hasil ke variabel, seperti di Listing 3-2.

Variabel number akan terikat ke nilai berdasarkan hasil ekspresi if. Jalankan kode ini untuk melihat apa yang terjadi:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.30s
     Running `target/debug/branches`
The value of number is: 5

Ingat bahwa blok kode mengevaluasi ke ekspresi terakhir di dalamnya, dan angka sendiri juga adalah ekspresi. Dalam kasus ini, nilai seluruh ekspresi if bergantung pada blok kode mana yang dieksekusi. Ini berarti nilai-nilai yang berpotensi menjadi hasil dari setiap arm if harus bertipe sama; di Listing 3-2, hasil baik arm if maupun arm else adalah integer i32. Jika tipe tidak cocok, seperti di contoh berikut, kami akan mendapat kesalahan:

Nama Berkas: src/main.rs

fn main() {
    let condition = true;

    let number = if condition { 5 } else { "six" };

    println!("The value of number is: {number}");
}

Saat kami mencoba mengompilasi kode ini, kami akan mendapat kesalahan. Arm if dan else memiliki tipe nilai yang tidak kompatibel, dan Rust menunjukkan tepat di mana menemukan masalah di program:

$ cargo run
   Compiling branches v0.1.0 (file:///projects/branches)
error[E0308]: `if` and `else` have incompatible types
 --> src/main.rs:4:44
  |
4 |     let number = if condition { 5 } else { "six" };
  |                                 -          ^^^^^ expected integer, found `&str`
  |                                 |
  |                                 expected because of this

For more information about this error, try `rustc --explain E0308`.
error: could not compile `branches` (bin "branches") due to 1 previous error

Ekspresi di blok if mengevaluasi ke integer, dan ekspresi di blok else mengevaluasi ke string. Ini tidak akan bekerja, karena variabel harus memiliki tipe tunggal, dan Rust perlu mengetahui secara pasti pada waktu kompilasi tipe apa variabel number. Mengetahui tipe number membiarkan compiler memverifikasi tipe valid di mana pun kami menggunakan number. Rust tidak akan bisa melakukannya jika tipe number hanya ditentukan pada runtime; compiler akan lebih kompleks dan akan membuat jaminan lebih sedikit tentang kode jika harus melacak beberapa tipe hipotetis untuk variabel apa pun.

Perulangan dengan Loop

Sering kali berguna untuk mengeksekusi blok kode lebih dari sekali. Untuk tugas ini, Rust menyediakan beberapa loops, yang akan menjalankan kode di dalam badan loop hingga akhir dan kemudian segera kembali ke awal. Untuk bereksperimen dengan loop, mari buat proyek baru bernama _loops_.

Rust memiliki tiga jenis loop: loop, while, dan for. Mari coba masing-masing.

Mengulang Kode dengan loop

Kata kunci loop memberitahu Rust untuk mengeksekusi blok kode berulang kali entah selamanya atau sampai Anda secara eksplisit memberitahunya untuk berhenti.

Sebagai contoh, ubah berkas _src/main.rs_ di direktori _loops_ Anda agar terlihat seperti ini:

Nama Berkas: src/main.rs

fn main() {
    loop {
        println!("again!");
    }
}

Saat kami menjalankan program ini, kami akan melihat again! dicetak berulang terus-menerus hingga kami menghentikan program secara manual. Kebanyakan terminal mendukung pintasan keyboard ctrl-C untuk menginterupsi program yang terjebak dalam loop terus-menerus. Cobalah:

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.08s
     Running `target/debug/loops`
again!
again!
again!
again!
^Cagain!

Simbol ^C mewakili tempat Anda menekan ctrl-C.

Anda mungkin atau tidak melihat kata again! dicetak setelah ^C, tergantung di mana kode berada di loop saat menerima sinyal interupsi.

Untungnya, Rust juga menyediakan cara untuk keluar dari loop menggunakan kode. Anda bisa menempatkan kata kunci break di dalam loop untuk memberitahu program kapan harus berhenti mengeksekusi loop. Ingat bahwa kami melakukannya di permainan tebak angka di bagian “Keluar Setelah Tebakan Benar” di Bab 2 untuk keluar dari program saat pengguna memenangkan game dengan menebak angka yang benar.

Kami juga menggunakan continue di permainan tebak angka, yang dalam loop memberitahu program untuk melewati sisa kode di iterasi loop ini dan pergi ke iterasi berikutnya.

Mengembalikan Nilai dari Loop

Salah satu kegunaan loop adalah mencoba ulang operasi yang Anda tahu mungkin gagal, seperti memeriksa apakah sebuah thread telah menyelesaikan pekerjaannya. Anda mungkin juga perlu meneruskan hasil operasi itu keluar dari loop ke sisa kode Anda. Untuk melakukannya, Anda bisa menambahkan nilai yang ingin Anda kembalikan setelah ekspresi break yang Anda gunakan untuk menghentikan loop; nilai itu akan dikembalikan keluar dari loop sehingga Anda bisa menggunakannya, seperti yang ditunjukkan di sini:

fn main() {
    let mut counter = 0;

    let result = loop {
        counter += 1;

        if counter == 10 {
            break counter * 2;
        }
    };

    println!("The result is {result}");
}

Sebelum loop, kami mendeklarasikan variabel bernama counter dan menginisialisasi ke 0. Kemudian, kami mendeklarasikan variabel bernama result untuk menampung nilai yang dikembalikan dari loop. Pada setiap iterasi loop, kami menambahkan 1 ke variabel counter, dan kemudian memeriksa apakah counter sama dengan 10. Saat itu, kami menggunakan kata kunci break dengan nilai counter * 2. Setelah loop, kami menggunakan titik koma untuk mengakhiri pernyataan yang menetapkan nilai ke result. Akhirnya, kami mencetak nilai di result, yang dalam kasus ini adalah 20.

Anda juga bisa return dari dalam loop. Sementara break hanya keluar dari loop saat ini, return selalu keluar dari fungsi saat ini.

Mendisambiguasi dengan Label Loop

Jika Anda memiliki loop di dalam loop, break dan continue berlaku untuk loop terdalam (innermost) pada titik itu. Anda bisa secara opsional menentukan label loop pada loop yang kemudian bisa Anda gunakan dengan break atau continue untuk menentukan bahwa kata kunci itu berlaku untuk loop berlabel alih-alih loop terdalam. Label loop harus diawali dengan kutip tunggal. Berikut contoh dengan dua loop bersarang:

fn main() {
    let mut count = 0;
    'counting_up: loop {
        println!("count = {count}");
        let mut remaining = 10;

        loop {
            println!("remaining = {remaining}");
            if remaining == 9 {
                break;
            }
            if count == 2 {
                break 'counting_up;
            }
            remaining -= 1;
        }

        count += 1;
    }
    println!("End count = {count}");
}

Loop luar memiliki label 'counting_up, dan ia akan menghitung naik dari 0 ke 2. Loop dalam tanpa label menghitung turun dari 10 ke 9. break pertama yang tidak menentukan label akan keluar dari loop dalam saja. Pernyataan break 'counting_up; akan keluar dari loop luar. Kode ini mencetak:

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.58s
     Running `target/debug/loops`
count = 0
remaining = 10
remaining = 9
count = 1
remaining = 10
remaining = 9
count = 2
remaining = 10
End count = 2

Menyederhanakan Loop Bersyarat dengan while

Sebuah program sering perlu mengevaluasi kondisi di dalam loop. Selama kondisi true, loop berjalan. Saat kondisi berhenti menjadi true, program memanggil break, menghentikan loop. Mungkin untuk mengimplementasikan perilaku seperti ini menggunakan kombinasi loop, if, else, dan break; Anda bisa mencoba itu sekarang di program, jika Anda mau. Akan tetapi, pola ini begitu umum sehingga Rust memiliki konstruksi bahasa built-in untuknya, yang disebut loop while. Di Listing 3-3, kami menggunakan while untuk mengulang program tiga kali, menghitung mundur setiap kali, dan kemudian, setelah loop, mencetak pesan dan keluar.

Konstruksi ini menghilangkan banyak nesting yang diperlukan jika Anda menggunakan loop, if, else, dan break, dan ini lebih jelas. Selama kondisi mengevaluasi ke true, kode berjalan; sebaliknya, ia keluar dari loop.

Melakukan Loop Melalui Koleksi dengan for

Anda bisa memilih menggunakan konstruksi while untuk melakukan loop melalui elemen-elemen sebuah koleksi, seperti array. Misalnya, loop di Listing 3-4 mencetak setiap elemen di array a.

Di sini, kode menghitung naik melalui elemen-elemen di array. Ia dimulai pada indeks 0 dan kemudian melakukan loop hingga mencapai indeks final di array (yaitu, saat index < 5 tidak lagi true). Menjalankan kode ini akan mencetak setiap elemen di array:

$ cargo run
   Compiling loops v0.1.0 (file:///projects/loops)
    Finished `dev` profile [unoptimized + debuginfo] target(s) in 0.32s
     Running `target/debug/loops`
the value is: 10
the value is: 20
the value is: 30
the value is: 40
the value is: 50

Kelima nilai array muncul di terminal, seperti yang diharapkan. Meski index akan mencapai nilai 5 pada beberapa titik, loop berhenti mengeksekusi sebelum mencoba mengambil nilai keenam dari array.

Namun, pendekatan ini rentan kesalahan; kami bisa menyebabkan program panic jika nilai indeks atau kondisi pengujian tidak benar. Misalnya, jika Anda mengubah definisi array a untuk memiliki empat elemen tapi lupa memperbarui kondisi ke while index < 4, kode akan panic. Ini juga lambat, karena compiler menambahkan kode runtime untuk melakukan pemeriksaan kondisional apakah indeks berada di dalam batas array pada setiap iterasi melalui loop.

Sebagai alternatif yang lebih ringkas, Anda bisa menggunakan loop for dan mengeksekusi beberapa kode untuk setiap item di koleksi. Loop for terlihat seperti kode di Listing 3-5.

Saat kami menjalankan kode ini, kami akan melihat keluaran yang sama seperti di Listing 3-4. Lebih penting lagi, kami kini telah meningkatkan keamanan kode dan menghilangkan peluang bug yang mungkin muncul dari melewati akhir array atau tidak cukup jauh dan melewatkan beberapa item. Kode mesin yang dihasilkan dari loop for bisa lebih efisien juga karena indeks tidak perlu dibandingkan dengan panjang array pada setiap iterasi.

Menggunakan loop for, Anda tidak perlu ingat mengubah kode lain jika Anda mengubah jumlah nilai di array, seperti yang Anda lakukan dengan metode yang digunakan di Listing 3-4.

Keamanan dan keringkasan loop for membuatnya konstruksi loop paling umum digunakan di Rust. Bahkan dalam situasi di mana Anda ingin menjalankan beberapa kode sejumlah kali tertentu, seperti contoh hitung mundur yang menggunakan loop while di Listing 3-3, kebanyakan Rustacean akan menggunakan loop for. Caranya adalah dengan menggunakan Range, yang disediakan oleh pustaka standar, yang menghasilkan semua angka berurutan mulai dari satu angka dan berakhir sebelum angka lain.

Berikut seperti apa hitung mundur akan terlihat menggunakan loop for dan metode lain yang belum kami bahas, rev, untuk membalik range:

Nama Berkas: src/main.rs

fn main() {
    for number in (1..4).rev() {
        println!("{number}!");
    }
    println!("LIFTOFF!!!");
}

Kode ini agak lebih bagus, bukan?

Ringkasan

Anda berhasil! Ini adalah bab yang cukup besar: Anda belajar tentang variabel, tipe data skalar dan majemuk, fungsi, komentar, ekspresi if, dan loop! Untuk berlatih dengan konsep yang dibahas di bab ini, coba bangun program untuk melakukan hal-hal berikut:

  • Mengubah suhu antara Fahrenheit dan Celsius.
  • Menghasilkan bilangan Fibonacci ke-n.
  • Mencetak lirik lagu natal “The Twelve Days of Christmas,” memanfaatkan pengulangan dalam lagu.

Saat Anda siap lanjut, kami akan membahas konsep di Rust yang tidak biasa ada di bahasa pemrograman lain: kepemilikan (ownership).
