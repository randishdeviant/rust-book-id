The Rust Programming Language

Halo, Dunia!

Sekarang setelah Anda menginstal Rust, saatnya menulis program Rust pertama Anda. Biasa saat belajar bahasa baru untuk menulis program kecil yang mencetak teks Halo, dunia! ke layar, jadi kami akan melakukan hal yang sama di sini!

Catatan: Buku ini mengasumsikan ketertarikan dasar dengan baris perintah. Rust tidak membuat tuntutan khusus tentang pengeditan atau alat atau di mana kode Anda berada, jadi jika Anda lebih suka menggunakan IDE daripada baris perintah, silakan gunakan IDE favorit Anda. Banyak IDE sekarang memiliki tingkat dukungan Rust tertentu; lihat dokumentasi IDE untuk detailnya. Tim Rust telah fokus pada mengaktifkan dukungan IDE yang hebat melalui rust-analyzer. Lihat Lampiran D untuk detail lebih lanjut.

Penyiapan Direktori Proyek

Anda akan mulai dengan membuat direktori untuk menyimpan kode Rust Anda. Tidak penting bagi Rust di mana kode Anda berada, tetapi untuk latihan dan proyek dalam buku ini, kami menyarankan membuat direktori _projects_ di direktori home Anda dan menyimpan semua proyek Anda di sana.

Buka terminal dan masukkan perintah-perintah berikut untuk membuat direktori _projects_ dan direktori untuk proyek “Halo, dunia!” di dalam direktori _projects_.

Untuk Linux, macOS, dan PowerShell di Windows, masukkan ini:

$ mkdir ~/projects
$ cd ~/projects
$ mkdir hello_world
$ cd hello_world

Untuk Windows CMD, masukkan ini:

> mkdir "%USERPROFILE%\projects"
> cd /d "%USERPROFILE%\projects"
> mkdir hello_world
> cd hello_world

Dasar Program Rust

Selanjutnya, buat berkas sumber baru dan namai _main.rs_. Berkas Rust selalu berakhir dengan ekstensi _.rs_. Jika Anda menggunakan lebih dari satu kata di nama berkas, konvensinya adalah menggunakan garis bawah untuk memisahkannya. Misalnya, gunakan _hello_world.rs_ bukan _helloworld.rs_.

Sekarang buka berkas _main.rs_ yang baru Anda buat dan masukkan kode di Listing 1-1.

Simpan berkas dan kembali ke jendela terminal Anda di direktori _~/projects/hello_world_. Di Linux atau macOS, masukkan perintah-perintah berikut untuk mengompilasi dan menjalankan berkas:

$ rustc main.rs
$ ./main
Halo, dunia!

Di Windows, masukkan perintah .\main sebagai pengganti ./main:

> rustc main.rs
> .\main
Halo, dunia!

Terlepas dari sistem operasi Anda, string Halo, dunia! seharusnya dicetak ke terminal. Jika Anda tidak melihat keluaran ini, rujuk kembali ke bagian “Pemecahan Masalah” di bagian Instalasi untuk cara mendapatkan bantuan.

Jika Halo, dunia! tercetak, selamat! Anda secara resmi telah menulis program Rust. Itu membuat Anda seorang programmer Rust—selamat datang!

Anatomi Program Rust

Mari tinjau program “Halo, dunia!” ini secara detail. Berikut potongan pertama dari puzzle ini:

fn main() {

}

Baris-baris ini mendefinisikan fungsi bernama main. Fungsi main istimewa: Selalu menjadi kode pertama yang dijalankan di setiap program Rust yang dapat dieksekusi. Di sini, baris pertama mendeklarasikan fungsi bernama main yang tidak memiliki parameter dan tidak mengembalikan apa pun. Jika ada parameter, parameter-parameter itu akan berada di dalam tanda kurung (()).

Badan fungsi dibungkus dalam {}. Rust mewajibkan tanda kurung kurawal di sekitar semua badan fungsi. Gaya yang baik adalah menempatkan tanda kurung kurawal pembuka di baris yang sama dengan deklarasi fungsi, menambahkan satu spasi di antaranya.

Catatan: Jika Anda ingin mempertahankan gaya standar di seluruh proyek Rust, Anda dapat menggunakan alat pemformat otomatis bernama rustfmt untuk memformat kode Anda dengan gaya tertentu (lebih lanjut tentang rustfmt di Lampiran D). Tim Rust telah menyertakan alat ini dengan distribusi Rust standar, seperti rustc, sehingga seharusnya sudah terinstal di komputer Anda!

Badan fungsi main menampung kode berikut:

#![allow(unused)]
fn main() {
println!("Halo, dunia!");
}

Baris ini melakukan semua pekerjaan di program kecil ini: Mencetak teks ke layar. Ada tiga detail penting yang perlu diperhatikan di sini.

Pertama, println! memanggil makro Rust. Jika memanggil fungsi sebagai penggantinya, akan ditulis sebagai println (tanpa !). Makro Rust adalah cara untuk menulis kode yang menghasilkan kode untuk memperluas sintaks Rust, dan kami akan membahasnya lebih detail di Bab 20. Untuk saat ini, Anda hanya perlu tahu bahwa menggunakan ! berarti Anda memanggil makro bukan fungsi normal dan makro tidak selalu mengikuti aturan yang sama seperti fungsi.

Kedua, Anda melihat string "Halo, dunia!". Kami meneruskan string ini sebagai argumen ke println!, dan string dicetak ke layar.

Ketiga, kami mengakhiri baris dengan titik koma (;), yang menunjukkan bahwa ekspresi ini berakhir, dan yang berikutnya siap dimulai. Kebanyakan baris kode Rust diakhiri dengan titik koma.

Kompilasi dan Eksekusi

Anda baru saja menjalankan program yang baru dibuat, mari periksa setiap langkah dalam prosesnya.

Sebelum menjalankan program Rust, Anda harus mengompilasinya menggunakan compiler Rust dengan memasukkan perintah rustc dan meneruskannya nama berkas sumber Anda, seperti ini:

$ rustc main.rs

Jika Anda memiliki latar belakang C atau C++, Anda akan memperhatikan bahwa ini mirip dengan gcc atau clang. Setelah kompilasi berhasil, Rust menghasilkan biner yang dapat dieksekusi.

Di Linux, macOS, dan PowerShell di Windows, Anda bisa melihat file yang dapat dieksekusi dengan memasukkan perintah ls di shell Anda:

$ ls
main  main.rs

Di Linux dan macOS, Anda akan melihat dua berkas. Dengan PowerShell di Windows, Anda akan melihat tiga berkas yang sama seperti yang Anda lihat menggunakan CMD. Dengan CMD di Windows, Anda akan memasukkan hal berikut:

> dir /B %= opsi /B mengatakan hanya menampilkan nama berkas =%
main.exe
main.pdb
main.rs

Ini menampilkan berkas kode sumber dengan ekstensi _.rs_, berkas yang dapat dieksekusi (main.exe di Windows, tetapi main di semua platform lain), dan, saat menggunakan Windows, berkas yang berisi informasi debugging dengan ekstensi _.pdb_. Dari sini, Anda menjalankan berkas main atau main.exe, seperti ini:

$ ./main # atau .\main di Windows

Jika main.rs Anda adalah program “Halo, dunia!”, baris ini mencetak Halo, dunia! ke terminal Anda.

Jika Anda lebih familiar dengan bahasa dinamis, seperti Ruby, Python, atau JavaScript, Anda mungkin tidak terbiasa mengompilasi dan menjalankan program sebagai langkah terpisah. Rust adalah bahasa ahead-of-time compiled, artinya Anda bisa mengompilasi program dan memberikan file yang dapat dieksekusi ke orang lain, dan mereka bisa menjalankannya bahkan tanpa Rust terinstal. Jika Anda memberi seseorang berkas _.rb_, _.py_, atau _.js_, mereka perlu memiliki implementasi Ruby, Python, atau JavaScript terinstal (masing-masing). Tetapi di bahasa-bahasa tersebut, Anda hanya butuh satu perintah untuk mengompilasi dan menjalankan program Anda. Semuanya adalah trade-off dalam desain bahasa.

Hanya mengompilasi dengan rustc sudah cukup untuk program sederhana, tetapi seiring proyek Anda berkembang, Anda akan ingin mengelola semua opsi dan memudahkan berbagi kode Anda. Selanjutnya, kami akan memperkenalkan Anda pada alat Cargo, yang akan membantu Anda menulis program Rust dunia nyata.
